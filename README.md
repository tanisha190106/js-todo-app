# JS Todo App

A simple Todo application built using Vanilla JavaScript.

## Features

- Add tasks
- View all tasks
- Delete tasks
- Exit the application

## Technologies Used

- HTML
- JavaScript

## How to Run

1. Open `index.html` in your browser.
2. Open the browser console (`F12` → Console).
3. Follow the prompts to manage your tasks.

- User input using `prompt()`
- Array methods like `push()` and `splice()`
